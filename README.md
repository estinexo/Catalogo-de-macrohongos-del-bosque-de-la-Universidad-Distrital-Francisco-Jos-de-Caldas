# Catálogo de Macrohongos del Bosque de la Universidad Distrital Francisco José de Caldas

Catálogo interactivo de macrohongos del Bosque de la Macarena y Vivero de la Universidad Distrital Francisco José de Caldas.

## 📂 Estructura del Proyecto

```
cositas bien phyton/
├── pagina principal.html      # Página de inicio
├── Agaricales.html            # Orden Agaricales
├── Auriculariales.html        # Orden Auriculariales
├── Boletales.html             # Orden Boletales
├── Polyporales.html           # Orden Polyporales
├── Russulales.html            # Orden Russulales
├── Tremellares.html           # Orden Tremellares
├── buscador.html              # Buscador de especies
├── buscador.js                # Base de datos y lógica de búsqueda
├── estilos.css                # Estilos del sitio
├── agaricales-familias/       # Páginas de familias de Agaricales
│   ├── Amanitaceae.html
│   ├── Agaricaceae.html
│   ├── Bolbitaceae.html
│   ├── Cortinariaceae.html

├── Agaricales/                # Imágenes de Agaricales
```

## 🌐 Despliegue en GitHub Pages

1. Sube este repositorio a GitHub
2. Ve a **Settings → Pages**
3. Selecciona la rama `main` y la carpeta `/ (root)`
4. Guarda y espera unos minutos

## 🔍 Funcionalidades

- Catálogo de macrohongos por orden taxonómico
- Buscador de especies con filtros (comestibles, tóxicos, micorrícicos, saprófitos)
- Carrusel de imágenes con animaciones GSAP
- Diseño responsive y adaptativo
